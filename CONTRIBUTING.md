# Contributing

These instructions apply equally to humans and coding agents.
Keep contribution guidance shared rather than maintaining separate
agent-specific instruction files.

## Workflow

### Issue tracker

When creating specs, planning tickets, or implementing tracked work,
follow [the local tracker conventions](docs/agents/issue-tracker.md).

### Triage labels

When assigning or changing a ticket's triage state, use
[the canonical labels](docs/agents/triage-labels.md).

### Domain documentation

Before designing, implementing, or reviewing changes, follow
[the domain documentation rules](docs/agents/domain.md).

### Verification

When implementing behavior, changing tests, or packaging checks, follow
[the testing policy](docs/design.md#implementation-verification).
