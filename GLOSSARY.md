# Voice dictation

Voice dictation converts spoken input into text for use in other applications.

## Language

**Dictation**:
Speech that the user intends to use as written text.
_Do not use as a synonym_: Voice command

**Dictation session**:
Speech that the user submits together to produce one transcript.
_Do not use as a synonym_: Conversation (a session can be one reply within a conversation)

**Finalization**:
The period after recording stops and before the transcript is ready to copy.
_Do not use as a synonym_: Recording (the microphone no longer captures audio for this session)

**Restart**:
The start of a new dictation session while the previous session is in finalization.
The application discards the previous session. Its transcript must not replace the clipboard.
_Do not use as a synonym_: Queue (a restart replaces a session instead of adding another behind it)

**Transcript**:
The written text that dictation produces.
_Do not use as a synonym_: Recording (which refers to audio, not text)

**Dictation indicator**:
The visual cue that shows recording, processing, success or failure.
_Do not use as a synonym_: Transcript preview (the indicator does not display the transcript)
